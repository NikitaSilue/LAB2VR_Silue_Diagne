UTILISATION DE L'IA DANS LE PROJET
#LAB2VR_Silue_Diagne
  
## Équipe - Nikita Silue - Rokhaya Diagne
  
## Comment jouer 
Dans ce jeu, vous vous reveiller dans la station Orion-7 : il y a l'alarme qui sonne avec l'eclerage d'urgence. Prenez les trois celules d'energies charger sur l'étagère de la salle des machines et placer les dans les trois bornes du PowerPanel pour rétablir le courant(les cellules non charger ne marcherons pas). Lisez ensuite le code a quatre chiffres qui sera afficher sur un panel dans la salle des machines, allez dans le poste de commande, entrez-le avec les boutons de la console pour lancer
l'appel de detresse, puis choisir Recommencer ou Quitter sur le panneau de fin. L' Alien dèrriere la vitre vous regarde.
Ps: Vous pouvez quitter à n'importe qu'elle moment avec le boutton sur votre poignet.
