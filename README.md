## Comment jouer 
Dans ce jeu, vous vous réveillez dans la station Orion-7 : il y a l'alarme qui sonne avec l'éclairage d'urgence. Prenez les trois cellules d'énergies chargées sur l'étagère de la salle des machines et placez-les dans les trois bornes du PowerPanel pour rétablir le courant (les cellules non chargées ne marcheront pas). Lisez ensuite le code a quatre chiffres qui sera afficher sur un panel dans la salle des machines, allez dans le poste de commande, entrez-le avec les boutons de la console pour lancer
l'appel de détresse, puis choisir Recommencer ou quitter sur le panneau de fin. L' Alien derrière la vitre vous regarde.
Ps: vous pouvez quitter à n'importe quel moment avec le bouton sur votre poignet.
